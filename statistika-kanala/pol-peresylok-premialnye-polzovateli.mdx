В этой части статистики отображается краткая сводная статистика по некоторым поведенческим факторам аудитории.

![](/images/statistika-kanala/pol-peresylok-premialnye-polzovateli-01.png)

**Пол аудитории** рассчитывается приблизительно на основании массива данных самых распространённых имён пользователей. Для того, чтоб подключить эту информацию для своего канала, воспользуйтесь инструментом “[Анализ аудитории](/drugie-instrumenty-analitiki/analiz-auditorii)”. При нажатии на показатели, открывается последний подробный анализ аудитории.\

![](/images/statistika-kanala/pol-peresylok-premialnye-polzovateli-02.png)

“**Пересылок поста, среднее**” показывает среднее значение пересылок каждого поста. Пересылки берутся из открытого API Telegram. Пересылкой считается репост в канал, чат, личные сообщения пользователей\

.![](/images/statistika-kanala/pol-peresylok-premialnye-polzovateli-03.png)

По кнопке можно открыть быстрый просмотр постов с сортировкой по числу просмотров, пересылок или количеству комментариев.

![](/images/statistika-kanala/pol-peresylok-premialnye-polzovateli-04.png)

В разделе "премиальные подписчики" отображается информация о premium подписчиках, которые подписались на канал в течение 6-ти крайних месяцев. \

![](/images/statistika-kanala/pol-peresylok-premialnye-polzovateli-05.png)\
