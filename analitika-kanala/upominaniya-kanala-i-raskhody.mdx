Для того, чтоб попасть в этот раздел необходимо открыть статистику канала и кликнуть по количеству упоминаний в Telegram.

![](/images/analitika-kanala/upominaniya-kanala-i-raskhody-01.png)

После этого откроется следующее окно:

![](/images/analitika-kanala/upominaniya-kanala-i-raskhody-02.png)

В этом разделе приблизительно можно подсчитать сколько канал потратил на своё продвижение. В разных нишах значения отличаются, учитывайте это при работе с этим разделом.

Из чего состоит раздел:

В первую очередь вы можете разделить все данные на периоды: По дням, По неделям, По месяцам

В каждом из периодов есть 5 столбцов

**День, Неделя, Месяц** — указывает на конкретный интервал, за который показаны данные

**Упоминаний** — количество упоминаний канала

**Репосты** — количество репостов постов канала в других каналах

**Охват** — суммарное количество просмотров на репостах и упоминаниях

**Потрачено** — приблизительная оценка затрат на размещения из расчета 300 cpm и при условии, что все упоминания были платными. Репосты не учитываются.

Таким образом можно приблизительно рассчитывать окупаемость каналов или отслеживать конкурентов.

Также есть возможность указывать своё значение CPM (стоимость рекламы за 1000 просмотров) с помощью окна CPM
