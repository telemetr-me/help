На вкладке «Динамика» собраны графики канала по дням и часам. Чтобы открыть её, откройте страницу канала и нажмите «Динамика» в ряду вкладок.

![Подписок и отписок по дням](/images/dinamika/podpisok-i-otpisok.png)

На вкладке есть графики:

- [«Подписок и отписок по дням»](/dinamika/podpisok-i-otpisok-po-dnyam)
- [«Динамика просмотров канала по часам»](/dinamika/dinamika-prosmotrov-kanala-po-chasam)
- [«Уведомления по дням»](/dinamika/uvedomleniya-po-dnyam)
- [«Охват публикаций за 24ч и число подписчиков»](/dinamika/okhvat-publikacii-za-24ch-i-chislo-podpischikov) и «Охват рекламных постов за 24ч»
- [«Суточный ER по дням»](/dinamika/sutochnyi-za-pervye-24ch-publikacii-vovlechyonnost-po-dnyam) и «Суточный ER рекламных постов по дням»
- [«Публикаций в день»](/dinamika/publikacii-v-den)
- [«Рекламных записей в день»](/dinamika/reklamnykh-zapisei-v-den)
- [«Рекламных упоминаний»](/dinamika/reklamnykh-upominanii)

Графики «Подписок и отписок по дням», «Динамика просмотров канала по часам» и «Уведомления по дням» есть только у каналов, которые подключили [детальную статистику](/drugie-instrumenty-analitiki/detalnaya-statistika). Остальные графики есть у всех каналов.

## Как работать с графиками

- Наведите курсор на график, чтобы увидеть значения за день.
- Чтобы приблизить период, зажмите левую кнопку мыши и проведите по графику. Чтобы вернуть весь период, нажмите на кнопку с лупой в правом верхнем углу графика.
- Если у графика есть переключатель «График / Таблица», нажмите «Таблица», чтобы увидеть те же данные по дням списком.

## Ограничения тарифа

На тарифе «Старт» графики показывают последние 7 дней. На платных тарифах период зависит от тарифа: от 3 месяцев на «Экономе» до 10 лет на «Корпорации». Чтобы видеть динамику за больший срок, [выберите тариф](https://telemetr.me/premium).
