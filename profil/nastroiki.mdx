Чтобы открыть настройки, перейдите в [профиль](/drugie-instrumenty-analitiki/profil) и выберите в меню «Настройки» или откройте [telemetr.me/profile/settings](https://telemetr.me/profile/settings).

## Способы входа

В Telemetr можно входить через почту, Telegram, Яндекс ID, MAX или ВКонтакте. Достаточно любого из привязанных способов. Рядом с каждым способом написано, привязан он или нет.

![Способы входа](/images/profil/sposoby-vhoda.png)

- «Почта». Вход по коду из письма и восстановление пароля. Чтобы привязать почту, введите адрес и нажмите «Привязать». Чтобы сменить почту, нажмите «Изменить почту», введите новый адрес, нажмите «Сохранить» и введите код из письма. Пока код не введён, вход остаётся по старому адресу.
- «Telegram». Подтверждает аккаунт и открывает [демо-доступ](/profil/tarif-start). Чтобы привязать Telegram, нажмите «Привязать Telegram». Если вы сменили имя или @username в Telegram, нажмите «Обновить имя и @username».
- «Яндекс ID». Вход в один клик, подтверждает аккаунт. Привязанный Яндекс ID сменить нельзя.
- «MAX». Вход и уведомления через мессенджер MAX. Нажмите «Привязать MAX» и подтвердите привязку в боте MAX.
- «ВКонтакте». Вход в один клик, но подтверждением аккаунта не считается.

Чтобы сменить привязанный Telegram или MAX, нажмите «Привязать другой» и подтвердите вход с нового аккаунта. Прежний аккаунт отвяжется. Уведомления в Telegram после смены нужно подключить заново. Если кнопки «Привязать другой» у Telegram нет, сменить его можно через [поддержку](https://t.me/TelemetrSupport).

Отвязать способ входа в настройках нельзя.

## Объединение учёток

Если у вас две учётки Telemetr, например одна с входом через Telegram, а другая через Яндекс ID, их можно объединить:

1. В блоке «Есть другая учётка Telemetr?» нажмите «Объединить учётки».
2. Подтвердите, что вторая учётка ваша: через Яндекс ID, через Telegram или почтой и паролем второй учётки.
3. Проверьте, какая учётка останется, а какая будет закрыта. Отметьте «Понимаю, что учётка №… закроется» и нажмите «Объединить учётки».

В оставшуюся учётку перейдут способы входа, ваши каналы, подписки на ботов и уведомления, а избранное скопируется. Сеансы закрытой учётки завершатся, её ключ API перестанет действовать. Отменить объединение можно через поддержку в течение 90 дней.

Если объединить автоматически нельзя, на странице будет написано «Автоматически объединить нельзя». В этом случае напишите в [поддержку](https://t.me/TelemetrSupport).

## Пароль

Пароль нужен для входа по почте, поэтому задать его можно только при привязанной почте.

- Чтобы сменить пароль, введите текущий пароль, затем новый пароль дважды и нажмите «Изменить пароль». Пароль должен быть не короче 6 символов.
- Если вы не помните текущий пароль, нажмите «Пришлите ссылку». На почту придёт ссылка для смены пароля, она действует час.
- Если вы входили только через Telegram, MAX, Яндекс ID или ВКонтакте, пароля у аккаунта нет. Введите новый пароль дважды и нажмите «Задать пароль».

## Подписка и автопродление

Блок «Подписка» показывает номер подписки и включено ли автопродление. Чтобы отключить автопродление, нажмите «Отключить автопродление». Оплаченный период сохранится, следующего списания не будет.

## Ключ API

В блоке «Ключ API» показаны ваш токен для API и MCP, дата его выдачи и дата последнего использования. Ключи и пакеты API настраиваются в разделе «API» профиля, туда ведёт кнопка «Ключи API и лимиты».

## Удаление аккаунта

1. Нажмите «Удалить аккаунт» и подтвердите действие.
2. Telemetr отправит подтверждение на почту, а если почты нет — в Telegram, ВКонтакте или MAX.
3. Перейдите по ссылке из подтверждения, а в MAX нажмите «Удалить аккаунт» в диалоге с ботом. Ссылка и кнопка действуют час.

Сразу после нажатия кнопки ничего не удаляется. После подтверждения аккаунт будет удалён, все сеансы завершатся, а ключи API перестанут действовать.

<Warning>
Если подписка ещё действует, неиспользованный период при удалении аккаунта не возвращается.
</Warning>
