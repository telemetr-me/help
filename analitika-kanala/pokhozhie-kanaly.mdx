Вкладка «Похожие каналы» показывает каналы, которые Telegram рекомендует подписчикам анализируемого канала. По ней удобно искать конкурентов и площадки для рекламы.

Чтобы открыть вкладку, откройте страницу канала и нажмите «Похожие каналы» в ряду вкладок. Вкладка появляется, если у Telemetr есть рекомендации для этого канала.

![Похожие каналы](/images/analitika-kanala/pokhozhie-kanaly.png)

Над таблицей указано, когда Telemetr последний раз обновлял рекомендации.

1. Сортировка. Выберите в списке «Сначала», в каком порядке показывать каналы: как их рекомендует Telegram, по подписчикам, по охвату поста, по ER, по оценке качества или по названию. Отсортировать можно и нажатием на заголовок столбца.
2. «Открыть». Открывает статистику канала в Telemetr.
3. «Ещё каналы по данным Telemetr». Нажмите, чтобы увидеть ниже список «Другие каналы по теме». Его подбирает Telemetr. Чтобы скрыть список, нажмите «Свернуть».

В таблице для каждого канала указаны число подписчиков, средний охват поста, ER, [оценка качества](/statistika-kanala/algoritm-ocenki-kachestva-kanala) и прирост подписчиков за месяц. Если канал продаёт рекламу на бирже Telemetr, вместо прироста стоит цена на бирже.

Если среди похожих есть каналы с биржи, над таблицей появляется переключатель «Все» / «Есть на бирже». Выберите «Есть на бирже», чтобы оставить только их.
