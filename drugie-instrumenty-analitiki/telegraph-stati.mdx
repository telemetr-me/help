В этом разделе собраны все ссылки на telegraph-статьи, которые публикуются в каналах.

> **Telegraph** — это анонимная блог-платформа, бесплатный издательский инструмент, созданный компанией Telegram. Хотя Telegraph создавался прежде всего как инструмент, позволяющий делиться длинными текстами в мессенджере Telegram, это полностью отдельный сервис, который можно использовать и без аккаунта в Telegram.

Раздел состоит из двух частей:

* Поиск
* Список статей

### Поиск

![](/images/drugie-instrumenty-analitiki/telegraph-stati-01.png)

**В тексте** — сюда вводится поисковой запрос, который нужно найти в статье.

**Тип поиска по тексту** — выбираем способ поиска необходимого контента

**Просмотров** — фильтр количества просмотров статьи

### Список статей

![](/images/drugie-instrumenty-analitiki/telegraph-stati-02.png)

Список статей состоит из следующих столбцов

* **Иллюстрация** — первое изображение в статье
* **Название** — название статьи (есть сортировка по алфавиту)
* **Количество просмотров за сегодня/вчера/всё время** (есть сортировка по каждому из показателей и по возрастанию, и по убыванию)
* **Упоминаний** — количество постов в которых упоминается ссылка на эту статью (есть возможность сортировки)
* **Описание** — краткое содержимое статьи, первые несколько предложений из статьи.
