# Инструкция Telemetr

Исходники инструкции help.telemetr.me на Mintlify. Каждая страница лежит отдельным файлом `.mdx`, меню и настройки сайта — в `docs.json`, картинки — в `images/<раздел>/`.

Править можно в веб-редакторе Mintlify или через pull request. После слияния в `main` Mintlify сам пересобирает сайт.

## Перенос с GitBook

20.10.2026 с GitBook перенесены 38 актуальных страниц с прежними адресами. 30 страниц не перенесены: они сильно устарели или описывают то, чего на сайте больше нет. Их будем писать заново, а пока их старые адреса ведут на первую страницу инструкции (список — `redirects` в `docs.json`). Когда новая страница готова, её переадресацию нужно убрать.
