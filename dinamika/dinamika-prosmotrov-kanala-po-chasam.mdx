График показывает, сколько просмотров канал получает в каждый час суток. По нему видно, когда аудитория активнее всего, и под эти часы можно ставить посты и рекламу.

График находится на вкладке [«Динамика»](/analitika-kanala/dinamika). Он есть только у каналов, которые подключили [детальную статистику](/drugie-instrumenty-analitiki/detalnaya-statistika): данные приходят из официальной статистики канала в Telegram.

![Динамика просмотров канала по часам](/images/dinamika/prosmotry-po-chasam.png)

По горизонтали часы от 0 до 23, по вертикали просмотры. Две линии сравнивают эту неделю и прошлую. Наведите курсор на график, чтобы увидеть точные числа за час.
